# תרגיל מסכם: Company Assistant (שקפים 57–59)

## אין כאן תיקייה נפרדת, ובכוונה

התרגיל המסכם הוא **בדיוק** הפרויקט שב-`server/` ועוד:

| דרישה מהשקף | איפה זה כבר קיים |
|---|---|
| 4 כלים לפחות | 3 ב-`server/`, הרביעי ב-`exercises/1-complete-task` |
| Endpoint אחד בלבד | `POST /api/agent/chat` |
| JWT חובה, כלים על המשתמש שב-Token | `authMiddleware` + `userId` ב-`executeTool` |
| ולידציה על כל ארגומנט | כל `case` ב-`executeTool.ts` |
| `answer` + `toolsUsed` | `AgentResult` ב-`agentService.ts` |

כלומר: **הפתרון של התרגיל המסכם הוא הפרויקט הזה + תרגיל 1.**

זו הסיבה שלא בניתי פרויקט שני. עותק שלם היה זהה ב-95% ומתחיל להיסחף
כבר בשבוע הראשון, וכל תיקון היה צריך לקרות פעמיים.

## מה התלמיד עדיין צריך לעשות בעצמו

1. לחבר את הכלי הרביעי (תרגיל 1) לתוך `allTools` ו-`executeTool`.
2. לכתוב את התיאורים של הכלים **מחדש, במילים שלו**, ולא להעתיק.
3. לעבור את בדיקת הקבלה למטה.

## בדיקת קבלה

חמש שאלות, בעברית ובאנגלית, שמפעילות ארבעה כלים שונים.
לכל אחת צריך לחזור `answer` הגיוני ו-`toolsUsed` נכון.

| # | ההודעה | הכלי המצופה |
|---|---|---|
| 1 | What is the warranty period? | `search_documents` |
| 2 | Add a task to buy milk | `create_task` |
| 3 | מה אני צריך לעשות היום? | `list_tasks` |
| 4 | Mark the milk task as done | `complete_task` |
| 5 | Who won the World Cup? | אף כלי, ותשובה שאומרת שזה מחוץ לתחום |

בדיקה שישית, לאבטחה: אותה בקשה **בלי** `Authorization` צריכה להחזיר `401`.

בדיקה שביעית, לוולידציה: אם המודל מחזיר `priority` שאינו ברשימה,
לא נוצרת שורה במסד. אפשר לאלץ זאת על ידי הרחבה זמנית של ה-`enum`
בהגדרת הכלי בלי לשנות את הוולידציה, ואז לבקש משימה "קריטית".

## הבונוסים (שקף 59)

| בונוס | רמז |
|---|---|
| סיכום מספרי | כלי חדש עם `SELECT priority, COUNT(*) ... GROUP BY priority`. **בלי LLM בספירה.** |
| לוג של קריאות לכלים | טבלת `tool_calls` עם `user_id`, `question`, `tool_name`, `args`, `created_at`. הבסיס לתרגיל 3 |
| מחיקה עם אישור | הכלי לא מוחק. הוא מחזיר `{ needsConfirmation: true, taskId }`, והמחיקה קורית ב-Endpoint נפרד שהמשתמש מפעיל בלחיצה |

הבונוס השלישי הוא החשוב מכולם, והוא מוביל ישירות למפגש 4.
