# תרגיל 3: מדידה

## השינוי

שורה אחת ב-`src/services/agentService.ts`, מיד אחרי הקריאה הראשונה:

```ts
const calls = first.functionCalls

console.log(
  'Q:', message,
  '| TOOL:', calls?.[0]?.name ?? 'none',
  '| ARGS:', JSON.stringify(calls?.[0]?.args ?? {})
)
```

גרסה מלאה יותר נמצאת ב-`agentService.logging.ts` שבתיקייה הזאת.

## מה מריצים

חמש שאלות. מומלץ לתת לכל זוג חמש **שונות**, כדי שיהיה מה להשוות בכיתה:

| # | השאלה | הכלי שנבחר | הארגומנטים |
|---|---|---|---|
| 1 | What is the refund policy? | | |
| 2 | Add a task to buy milk | | |
| 3 | What do I need to do today? | | |
| 4 | תוסיף משימה דחופה לסיים את הדוח | | |
| 5 | Do you ship to Brazil? | | |

## מה מחפשים

שאלה **אחת** שבה המודל בחר לא נכון, ולתקן אותה **דרך התיאור בלבד**.

אסור: להוסיף `if` ב-`executeTool`, לשנות את `runAgent`, או לתקן
את השאלה עצמה.

## שאלות טובות לשבור איתן

אלה שאלות שנוטות לבלבל, ולכן הן חומר גלם מצוין:

- `Remind me about the warranty` — האם זו יצירת משימה או שאלה על מסמך?
- `What did I ask you to buy?` — משימות, אבל נשמע כמו חיפוש
- `Show me everything` — אין לו מספיק מידע להחליט
- `תבדוק מה כתוב על אחריות ותוסיף לי משימה` — שתי פעולות בהודעה אחת

האחרונה תמיד תיכשל חלקית, כי `runAgent` מריץ כלי אחד. זה בכוונה.

## מה מגישים

הטבלה מלאה, ועוד שורה אחת: איזה תיאור שיניתם, ומה זה תיקן.
